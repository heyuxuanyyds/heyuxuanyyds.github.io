备份与恢复

导出为 JSON。导入会逐篇写入 GitHub 仓库，覆盖同路径文件前会读取当前版本。

部署提示

仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。之后文章更新会自动部署；定时发布由每 15 分钟运行一次的 Actions 任务检查。

GitHub Actions 定时任务可能有延迟；仓库长期无活动时 GitHub 也可能暂停 schedule，届时在 Actions 页面手动运行一次即可恢复。
